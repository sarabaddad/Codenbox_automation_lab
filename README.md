# Selenium Automation Practice – CodeBox

This project contains automated test scripts built using Selenium WebDriver and TestNG to practice different web automation techniques on the following practice website:
https://codenboxautomationlab.com/practice/

# The tests simulate common user interactions and validate expected behaviors on the page.


# Features Covered
- Radio button selection with random choice
- Dynamic and static dropdown handling
- Checkbox interaction and validation
- Switching between browser windows and tabs
- Handling JavaScript alerts and confirmations
- Reading data from web tables
- Show / hide element validation
- Enable / disable element testing
- Mouse hover actions
- Taking screenshots using Selenium
- Working with iframes
- Basic calendar interaction



# Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Microsoft Edge WebDriver

# Purpose
This project was created to practice Selenium automation testing concepts and explore different types of web elements and browser interactions commonly used in UI test automation.
